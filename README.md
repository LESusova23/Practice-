PracticeProject: Система за управление на ИАРА
Това е специализирана софтуерна система, разработена за нуждите на Изпълнителна агенция по рибарство и аквакултури (ИАРА). Проектът е насочен към автоматизиране на процеси, свързани с управлението на риболовната дейност и мониторинга на обектите.

Основни функционалности
Управление на кораби: Поддържане на регистър с данни за риболовните плавателни съдове.

Мониторинг на разрешителни: Система за проследяване и валидиране на разрешителни за риболов.

База данни: Използване на SQLAlchemy за надеждно съхранение на информацията в SQLite.

Технологичен стек
Език: Python 

Уеб рамка: Flask

База данни: SQLAlchemy (SQLite)

Структура на проекта
app.py: Главен входен файл и конфигурация на сървъра.

models.py: Дефиниции на обектите в базата данни (кораби, лицензи).

templates/: HTML шаблони за потребителския интерфейс.

static/: Статични файлове (CSS стилове).
